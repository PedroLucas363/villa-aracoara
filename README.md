# Villa Aracoara

Protótipo da landing page da pousada Villa Aracoara, na Praia do Preá (Cruz, CE).

- `site/` — código da landing (Vite + React + TypeScript, Tailwind, Motion, Lenis). Veja [site/README.md](site/README.md).
- `assets/` — fotos originais; `npm run images` (dentro de `site/`) gera as versões otimizadas.

Cada push na `main` compila o site e publica no GitHub Pages (`.github/workflows/pages.yml`).
